# DevOps Capstone Project 01

## Objective
Build a local CI/CD platform with automated testing,
containerization, deployment, security, and observability.

## Environment
- Operating System: Windows 11
- Linux: Ubuntu on WSL 2
- Language: Python
- Deployment: Local only

## Project Structure
- app/: Application source code
- tests/: Automated tests
- scripts/: Local CI scripts
- docs/: Project documentation
